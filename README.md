# Calculator Project

A simple calculator built using **HTML, CSS, and JavaScript**.

## Features

* Basic arithmetic operations (+, -, ×, ÷)
* Responsive design
* Dark/Light mode
* Hover effects on buttons
* User-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Preview

Live Demo: https://ajay-maurya-dev.github.io/Calculater/

## How to Use

1. Open the calculator.
2. Click the buttons to enter numbers.
3. Perform calculations.
4. Use Dark/Light mode for theme switching.
